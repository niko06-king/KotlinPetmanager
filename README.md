# 🐾 KotlinPet Manager

Aplicación móvil desarrollada en Android Studio utilizando Jetpack Compose y la arquitectura MVVM para el registro y gestión en tiempo real de pacientes veterinarios.

## Estudiante
- Nombre Completo: [Nicolas leon Ramirez]
- Código de Estudiante: [1085717352]

##  Descripción de la Aplicación
KotlinPet Manager es una herramienta interactiva para clínicas veterinarias. Permite ingresar información de los pacientes (nombre, especie/raza, edad y marcar si es urgencia médica) y desplegarlos en tiempo real dentro de una lista dinámica con diseño Material 3.

##  Arquitectura
- **Lenguaje:** Kotlin
- **Diseño de Interfaz:** Jetpack Compose & Material 3
- **Arquitectura:** MVVM (Model - View - ViewModel)
- **Control de Versiones:** Git & GitHub
